# Exact, tested versions of every runtime and test dependency (a pip
# constraints file, not a requirements file: it pins versions but installs
# nothing by itself). requirements*.txt state the supported ranges; this
# file is what the image, CI and the scraper smoke actually install:
#
#   pip install -r requirements.txt -c constraints.txt
#
# Without it every image rebuild re-resolved "latest", which is how a fresh
# build picked up SQLAlchemy 2.1 without greenlet (async engine unimportable)
# and how a resolver could choose python-jobspy 1.1.13 (no `hours_old`).
#
# Regenerate after changing requirements*.txt (keeps this header), then
# run the test suite:
#
#   { sed '/^[a-z]/,$d' constraints.txt
#     uv pip compile requirements-dev.txt --python-version 3.11 \
#       --python-platform x86_64-manylinux_2_28 --no-header --no-annotate
#   } > constraints.new && mv constraints.new constraints.txt
#
# 3.11 matches the Dockerfile; the same pins also resolve on 3.12 (CI).
